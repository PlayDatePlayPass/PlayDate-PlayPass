🔒 Your Data is Private

Your kids' info is saved only in this phone's browser. No servers, no accounts, no tracking.

When you share, the info you pick is packed into the link itself, after a #. Browsers never send that part to any website, so only the host's phone unpacks it.

  • Anyone who has the link can read the card. If the host forwards it, the new reader can see it too.
  • Links never expire and you can't unsend them, so share only what this host needs.
  • Clearing browser data or switching phones deletes your saved kids. Use Export backup in the app.
  • The app can't confirm the host opened it.
